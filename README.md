# 賽後訪問回答工作臺

「運動與媒體」課程的賽後訪問受眾轉譯練習頁。學生扮演運動員回答記者提問，頁面即時檢核三個要點：

1. **關鍵畫面**：哪一刻、發生了什麼
2. **原因**：為什麼會發生的具體機制
3. **下一步**：下一場或訓練中可觀察的調整

送出後，採訪記者會追問一題、教練給一項修正建議。學生依建議改寫，至少完成 2 輪，再複製純文字紀錄繳交。

**練習情境**：網球、高爾夫球、健美、空手道、游泳、排球，另可自訂問題。

## 使用

開啟 GitHub Pages 網址即可，不需要任何帳號。整個頁面是單一檔案 `index.html`，不收集、不上傳任何作答資料；學號與姓名只存在學生自己的瀏覽器。

## 說明

此版本的記者與教練回饋依檢核結果產生（規則式），不使用 AI。回饋不會驗證賽事事實。
